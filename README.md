# 수학 AI 스튜디오

초등 4학년 수학 영재 특강 「나는 수학 프로그램 디자이너 — SW·AI로 완성하는 나만의 수학 인공지능 프로그램」 수업 사이트입니다.

- `index.html` 수업 허브 (만나기 → 체험하기 → 해부하기 → 설계하기 → 만들기(캔바) → 공유하기(작품 전시관) → 돌아보기)
- `apps/` 체험 앱 3개: 넘버 갤럭시 · 도형 코딩봇 · 패턴 AI 연구소 (2022 개정 수학 4-1, 1~6단원)
- `assets/` ChatGPT로 그린 그림과 게임 공용 코드
- `config.js` 공유 게시판(Apps Script) 연결 주소
- `apps-script/Code.gs` 게시판 저장소 코드
- 준비 방법은 `시작하기.html` 참고

진행 기록은 각 브라우저(localStorage)에만 저장되고, 게시판 글만 선생님 구글 시트에 저장됩니다.
