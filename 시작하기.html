① 인터넷 주소 만들기 (GitHub Pages)

  1. GitHub에서 새 저장소 math-ai-studio 를 Public으로 만들기
  2. Add file → Upload files → 이 폴더 안의 파일·폴더를 모두 끌어다 놓기 → Commit changes
  3. Settings → Pages → Branch: main / (root) → Save → 1~2분 뒤 https://아이디.github.io/math-ai-studio/
아이들에게는 이 주소 하나만 주면 돼요. 허브의 선생님 메뉴 → 반별 접속 QR에서 4-1반·4-2반 QR을 골라 띄우면, 그 QR로 들어온 기기는 반이 자동으로 골라져요(주소 끝 ?ban=4-1). QR 없이 들어오면 처음에 반을 고르는 창이 떠요. 앞 반이 쓰던 기기에서 다른 반을 고르면 그 기기의 이름·설계 카드·게임 기록이 지워지고 새로 시작해요.

② 공유 게시판 연결 (3분)

아이들이 계정 없이 작품과 칭찬을 올리면 선생님 구글 드라이브의 시트 「수학 AI 스튜디오 공유 게시판 (2026 영재 특강)」에 저장돼요. 시트는 미리 만들어 두었어요.

  1. 그 시트를 열고 메뉴 확장 프로그램 → Apps Script
  2. 원래 코드를 지우고 apps-script/Code.gs 내용을 통째로 붙여 넣기 → 저장
  3. 오른쪽 위 배포 → 새 배포 → 톱니바퀴 → 웹 앱 · 실행: 나 · 액세스: 모든 사용자 → 배포 → 권한 승인(계정 선택 → 고급 → 이동 → 허용)
  4. 나온 웹 앱 URL을 복사해 config.js 의 따옴표 안에 붙여 넣고, GitHub에 config.js만 다시 올리기
  5. 시트 posts 탭의 cls 칸에 작품을 올린 반(4-1반/4-2반)이 적혀요. 전시관에서는 우리 반 작품이 먼저 보이고, 모든 반을 누르면 두 반 작품을 함께 볼 수 있어요.
연결 전에는 게시판이 미리보기 모드(그 기기에만 저장)로 동작해요. 연결되면 전시관 위에 실시간 연결됨 표시가 떠요. 선생님 메뉴 → 비밀번호 2022 → 관리 켜기로 글을 숨길 수 있어요(비밀번호는 Code.gs 맨 위에서 바꿀 수 있어요). 욕설은 저장 전에 걸러져요.

③ 캔바 확인

  1. 초대 링크로 학생이 들어오면 우리 반(팀)에 참여돼요. 허브 5단계에 링크와 QR이 있어요.
  2. 캔바 교육용에서는 선생님이 Canva Code 사용을 허용해야 학생 화면에 ‘코드’가 보여요. 수업 전에 학생 계정으로 한 번 확인해 주세요.
  3. 학생 작품은 게시(Publish) → 사이트 주소 복사 → 전시관에 붙여 넣기. 게시가 막혀 있으면 공유 → 링크 복사로 올려도 돼요.

수업 흐름 예시 (120분)

10분1 만나기 — 미니 곱셈 도우미로 ‘입력 → 규칙 → 출력’ 체험
25분2 체험하기 — 예시 앱 3개(앱당 7~8분), 관찰 미션 체크, 일부러 틀려 보기
10분3 해부하기 — 비교표와 프로그램 종류 메뉴판, 아이디어 은행
15분4 설계하기 — 설계 카드 작성 → 주문서 복사
40분5 만들기 — 캔바 AI(코드)로 제작, 고치기 주문으로 다듬기, 정답 검사 체크리스트
15분6 공유하기 — 전시관에 올리고 친구 작품 체험 후 잘한 점·인상 깊은 점 남기기
5분7 돌아보기 — 디자이너 노트와 배지
선생님 메뉴의 타이머(3·5·10·15·25분)를 활동마다 쓰면 편해요.
